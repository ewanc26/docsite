[bean-dumper](https://github.com/ewanc26/bean-dumper) is an early Python learning project, kept in the archive for historical interest. It is not maintained and not intended for use.

The script downloads a file from a URL to the Windows Downloads folder, then copies it to any drive where a file named `beans.jpg` already exists. It was written as a practice exercise for working with `requests`, `pywin32`, and file system operations.

## Status

Unmaintained. Windows-only. Not recommended for any practical purpose.
