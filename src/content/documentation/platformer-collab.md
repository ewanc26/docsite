[platformer-collab](https://github.com/ewanc26/platformer-collab) is a simple 2D platformer made in Godot 4 (Mono/C#) as a two-person collaboration. It uses free assets from [Kenney](https://kenney.nl).

## Setup

**macOS**

1. Install Godot Engine Mono from [godotengine.org](https://godotengine.org/download)
2. Clone the repo: `git clone git@github.com:ewanc26/platformer-collab`
3. Open `project.godot` in Godot

**Arch Linux**

```bash
sudo pacman -S godot-mono
git clone git@github.com:ewanc26/platformer-collab
```

Then open `project.godot`.

## Running

Click the Play button in Godot's top-right corner.
