[azurite](https://github.com/ewanc26/azurite) is a very basic Bluesky client for macOS. It's experimental — built for fun, not for long-term development.

Expect poor Swift code quality. This is a learning project.

## Features

- Basic Bluesky timeline viewing
- Native macOS interface
- AT Protocol integration

## Status

This project is not actively maintained. It was built as a learning exercise for Swift and macOS development.

## Requirements

- macOS
- Xcode
